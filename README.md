# Two_Stage_ECG_Monitoring
This repo contains the code of Beyond Black-Box Models: An Interpretable Two-Stage Framework for ECG Rhythm Monitoring

# Abstract
Models for continuous ECG monitoring in resource-constrained environments should be accurate, computationally efficient, and interpretable. Although deep learning models can achieve strong performance, they often require substantial computational resources and provide limited transparency for clinical interpretation. This work proposes an uncertainty-aware hierarchical framework for ECG rhythm classification. Stage-1 employs a lightweight Random Forest classifier for coarse rhythm classification and uncertainty estimation. The estimated uncertainty is then used to determine whether Stage-2 inference is required. Stage-2 operates on an extended feature representation consisting of Time-Domain Morphological Features (TDMF) combined with Stage-1 posterior probabilities and uncertainty measures. Random Forest, XGBoost, and LightGBM classifiers are optimized using multi-objective Bayesian optimization with objectives including classification performance, inference latency, and model complexity. An Edge-Aware Utility (EAU) score is further introduced to prioritize Pareto-optimal configurations under deployment-oriented constraints. The proposed framework additionally generates explainable AI packets containing predictions, uncertainty estimates, gating decisions, and SHapley Additive exPlanations (SHAP)-based feature attributions. Experiments conducted on the MIT-BIH Arrhythmia Database demonstrate favorable trade-offs between diagnostic performance and computational efficiency.
